# AgencyCalc

Practical calculators for freelance web developers and small agencies.

Built with **Next.js (App Router)**, **TypeScript (strict)**, and **Tailwind CSS**.
Client-side only — no database, auth, payments, or analytics.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
```

## Commands

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — ESLint (`next/core-web-vitals`)
- `npm run typecheck` — TypeScript check (`tsc --noEmit`)

## Pages

- `/` — Website Project Quote Calculator
- `/maintenance` — Website Maintenance Pricing Calculator
- `/scope-creep` — Scope-Creep Cost Calculator
